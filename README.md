## Project Overview
This is a K9 website where people are encouraged to train their dogs for protection training with the company, the company also has resources and dogs which they sell.
The website is made genuinely for any one interested in dog protection services weather individuals or companies and so on. 

## Website Goals and Objectives
Inform clients or communities about the specific roles working dogs play in security and protection.

## Key Features and Functionality
* Responsive design for mobile and desktop.
* Interactive contact form.
* Dynamic product gallery.

## Changelog

### Added
- **CSS Reset:** Universal reset for `margin`, `padding`, and `box-sizing`.
- **Grid Layout:** Added `.container` class with a 3 column CSS Grid.
- **Responsive Images:** Added `.responsive-image` helper class.
- **Base Styles:** Added default overrides for `li` and `a` tags.

### Changed
- **Navigation:** Updated `nav` layout to Flexbox with custom hover states.
- **Header & Typography:** Applied font sizing, families, and colors to `header`, `h1`, and `h2`.
- **Responsive Breakpoints:** Added media queries for **768px** and **480px** viewports to adapt layouts for mobile and tablet devices.

### Fixed
- **Color Definition:** Flagged invalid syntax `yellow(3, 61, 138)` on the header background for correction to standard `rgb()`.
